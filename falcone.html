🎭 Simulação de Demonstração
Cria solicitações, voluntários e confirmações fictícias numa cidade escolhida, para demonstrar a plataforma em reuniões comerciais sem precisar de uma catástrofe real em andamento. Tudo marcado como simulação e fácil de remover depois.
➕ Criar cenário de demonstração
🧹 Limpar simulação ativa
Remove permanentemente as solicitações, voluntários e confirmações marcados como simulação — não afeta nenhum dado real de produção. Apague uma cidade específica, ou tudo de uma vez.
☢️ Zona de Risco
Ações nesta página são permanentes e não podem ser desfeitas pelo sistema. Um backup em JSON é baixado automaticamente antes de qualquer exclusão, mas a restauração precisa ser feita manualmente no banco de dados.
💾 Backup completo do site
Baixa um arquivo JSON com todos os dados de todas as tabelas do site (solicitações, voluntários, confirmações, pontos de apoio, prefeituras, bloqueios, avaliações, registros de chuva, endereços bitcoin, e demais). Ação segura — não exclui nem altera nada, só faz uma cópia.
📤 Restaurar a partir de um backup
Envie um arquivo de backup (gerado pela opção acima) para reimportar os dados. Registros com o mesmo ID são atualizados; registros novos são criados. Use em caso de pane, perda de dados, ou ataque.
🗺️ Excluir dados por região
Remove permanentemente solicitações, voluntários, confirmações, pontos de apoio, prefeituras e bloqueios de uma cidade, estado ou país específico.
🏆 Zerar pontuação do ranking
Zera o campo de pontos dos voluntários, sem excluir confirmações, avaliações, solicitações ou qualquer outro dado. O histórico de ajudas permanece intacto — só o placar é resetado.
💣 Excluir TODOS os dados do site
Remove permanentemente todas as solicitações, voluntários, confirmações, pontos de apoio, prefeituras e bloqueios, de qualquer cidade, estado ou país. Não há filtro — é tudo.
Regiões Bloqueadas
Impede que novas solicitações ou pontos de apoio sejam cadastrados a partir de países, estados ou cidades específicas. Por padrão, qualquer lugar pode cadastrar — esta lista define as exceções.
